# One Star for Monday

Entry for the make.fun competition
`u-clever-harbor-75-one-star-for-monday-9ead4a61`: a one-line, one-star
review of Monday.

`main.py` writes one original line (109 characters, 20 words) to
`/output/entry.txt`. The line is deterministic — the same line on every run.

## The line

> One star. Monday arrived at 6:04, drank my coffee, stole my clean shirt, and asked me to rate the experience.

Monday shows up uninvited at 6:04, helps itself to the coffee and the clean
shirt, and then — the twist — asks to be rated. This review is the answer.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
